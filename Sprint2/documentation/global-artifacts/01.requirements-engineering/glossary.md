# Glossary
| **_TEA_ (EN)**                         | **_TEA_ (PT)**                     | **_Description (EN)_**                                                                                                                                                                                                                                                                                                                                                           |
|-----------------------------------------|-------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Agile Approach**                      | Abordagem fácil                    | A project management method promoting iterative and incremental development. In this project, it is implemented through the SCRUM methodology.                                                                                                                                                                                                                                   |
| **Assembly Operations**                 | Operações de montagem              | A set of operations needed to assemble the components of a final product. These operations are represented in the branches of the Bill of Materials (BOM) tree structure.                                                                                                                                                                                                         |
| **BDDAD**                               | Base de dados                      | A system used to store and organize data. In this project, a database will be designed to                                                                                                                                                                                                                                                                                        |
| **BOM**                                 | Lista de materiais                 | A tree-like structure that details the final products, raw materials, and components, along with their quantities, required to produce the final product.                                                                                                                                                                                                                        |
| **BOO**                                 | Recibo de operações                | A tree structure representing the operations and sequences needed to produce a product.                                                                                                                                                                                                                                                                                          |
| **BOO Template**                        | Modelo BOO                         | A pre-defined template for a Bill of Operations, facilitating the creation of variants within a product family by reusing structures.                                                                                                                                                                                                                                            |
| **Customer Order**                      | Pedido do cliente                  | A client request that may include multiple items, each with possible variants (such as size and color). The order also contains information such as delivery date and location.                                                                                                                                                                                                   |
| **Circular Buffer**                     | Buffer Circular                    | A data structure used to store data in a continuous loop, enabling efficient insertion and deletion operations. Commonly used for production simulations or machine monitoring.                                                                                                                                                                                                  |
| **Critical Path Operations**            | Operações do Caminho Crítico       | Operations identified as essential or with the longest sequence in a production tree, used to allocate resources efficiently.                                                                                                                                                                                                                                                    |
| **Domain Model**                        | Modelo de domínio                  | A domain model is a visual representation used to depict the essential entities, attributes, relationships, and behaviors within a specific problem domain.                                                                                                                                                                                                                      |
| **Factory Facilities**                  | Instalações de fábrica             | Refers to the plant layout, its stations, and work areas (robots, automated machines, or human-operated machines) that carry out production operations.                                                                                                                                                                                                                           |
| **Flow-shop**                           | Flow-shop                          | A specific type of JobShop where production is limited to a restricted number of product families, with well-defined operations.                                                                                                                                                                                                                                                  |
| **Iterative and Incremental Process**   | Processo iterativo incremental     | A development method where the system is built in steps, constantly reviewed and improved through cycles.                                                                                                                                                                                                                                                                         |
| **JobShop**                             | JobShop                            | A manufacturing model that handles a wide variety of products, with short production runs and high flexibility. It is characterized by different sets of operations for each product.                                                                                                                                                                                                                                   |
| **Kanban**                              | Kanban                             | A visual management system that helps optimize workflow, often used in agile approaches like SCRUM.                                                                                                                                                                                                                                                                              |
| **Layout**                              | Layout                             | The physical arrangement of stations and equipment on a production floor, considering operation sequences and space efficiency.                                                                                                                                                                                                                                                  |
| **Machine Operation**                   | Operação da máquina                | A process performed by a station or machine during the manufacturing of a product.                                                                                                                                                                                                                                                                                               |
| **MachManager Component**               | Componente MachManager             | A software module responsible for managing production machines, forwarding commands, and tracking machine states.                                                                                                                                                                                                                                                                |
| **MVP**                                 | Produto mínimo viável              | The simplest version of a product with basic functionality that satisfies initial user needs and provides feedback for further development.                                                                                                                                                                                                                                       |
| **Non-functional Requirements**         | Requisitos Não-funcionais          | Criteria for system implementation that include data integrity, system interoperability, maintainability, coding standards, and documentation best practices.                                                                                                                                                                                                                    |
| **Plant Floor**                         | Chão de fábrica                    | The physical space in a factory where production occurs, made up of workstations that perform various operations.                                                                                                                                                                                                                                                                 |
| **Preventive Maintenance**              | Manutenção preventiva              | Scheduled maintenance aimed at preventing machine failures and ensuring operational efficiency.                                                                                                                                                                                                                                                                                   |
| **Production Control**                  | Produção controlada                | The process of overseeing and adjusting production to ensure products are manufactured according to the established plan, including machine supervision and maintenance scheduling.                                                                                                                                                                                               |
| **Production Engineering**              | Engenharia de produção             | Involves the planning and design of products and components, as well as load analysis, determining the technical and economic feasibility of a project.                                                                                                                                                                                                                           |
| **Production Manager**                  | Gerente de produção                | Responsible for managing information related to products and materials used in the factory, as well as controlling production orders.                                                                                                                                                                                                                                             |
| **Production Order**                    | Ordem de produção                  | A document specifying the tasks necessary to produce an item based on the BOM and BOO. It is directly related to customer orders.                                                                                                                                                                                                                                                 |
| **Production Planning**                 | Produção planeada                  | The process of generating a production plan based on customer orders and available resources. This plan defines the sequence of operations and the stations to be used.                                                                                                                                                                                                           |
| **Production Tree**                     | Árvore de Produção                 | A hierarchical representation of operations, components, and materials required to produce a product. It provides a complete structure for understanding production dependencies and steps.                                                                                                                                                                                       |
| **Project-Based Manufacturing**         | Manufatura de projetos             | A production type focused on specific projects, usually involving unique and complex products with long lead times.                                                                                                                                                                                                                                                               |
| **Scaled-down Ventilation System**      | Sistema de Ventilação Reduzido     | A hardware and software prototype representing a simplified version of a ventilation and exhaust system, integrating sensors and actuators for monitoring environmental parameters.                                                                                                                                                                                               |
| **SCRUM**                               | SCRUM                              | An agile methodology used for managing project development, structured in sprints where teams collaborate to achieve specific goals within short timeframes.                                                                                                                                                                                                                       |
| **Short-Run Production**                | Produção a curto prazo             | A production type focused on creating small batches of products, often with high customization and flexibility.                                                                                                                                                                                                                                                                   |
| **Simulation Enhancements**             | Melhorias na Simulação             | Features added to improve simulation accuracy, such as priority-based processing, average execution times, and dependency tracking.                                                                                                                                                                                                                                               |
| **Software application**                | Aplicação de _Software_            | Is a computer program designed to help people perform an activity.                                                                                                                                                                                                                                                                                                                |
| **Sprint**                              | Sprint                             | A defined work period within the SCRUM methodology, typically four weeks long, where a development team focuses on specific goals.                                                                                                                                                                                                                                                |
| **SSD Diagram**                         | Diagrama de sequência de sistema   | System Sequence Diagram, is a visual representation used to depict the flow of interactions between external actors and the system under consideration.                                                                                                                                                                                                                            |
| **TDD**                                 | Desenvolvimento orientado a testes | A software development approach where tests are written before the code implementation, ensuring the solution functions as expected from the start.                                                                                                                                                                                                                               |
| **US**                                  | Histórias do usuário               | Short, simple descriptions of a system feature from the end user's perspective. They guide development in the context of agile methodologies.                                                                                                                                                                                                                                      |
